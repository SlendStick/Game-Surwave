# Surwave 1.4.14 — читаемые опасные зоны

На вашем скриншоте обведено **туманное бурое пятно с рваной красной окружностью** — это зона опасности (`Hazard`), а именно зона зыбучих песков: событие карты «Выжженные Пески» каждые ~72 секунды ставит 5 таких зон у игрока. Пятно — заливка зоны, рваная окружность — её затухающая вспышка при активации.

Проблема была в виде: зона рисовалась одной размытой кляксой без границы, поэтому понять, где край и когда рванёт, было нельзя.

## Что изменилось

Новый визуал зоны (`scripts/game/hazard_vis.gd`, рисуется кодом):

- **чёткая кайма** по границе — видно, куда нельзя наступать;
- **вращающийся пунктир** по краю — отличает активную зону от декорации и от лужи;
- **ядро темнее к центру** — зона читается как «яма», а не как светлое пятно;
- **таймер предупреждения**: пока зона не активна, вокруг растёт золотой круг и мигает внешнее кольцо — видно, когда рванёт;
- узор внутри зависит от типа: `swirl` — зыбучие пески и трясина, `rune` — проклятия, `fire` — огонь и извержения.

Заменён и сам способ отрисовки: раньше зона была спрайтом из единственного кружка-текстуры (`projectile_orb`, тот же, что у снарядов), отсюда «пятно из ничего». Теперь это отдельный узел рисования с границами, пунктиром и узором — и снаряды с зонами больше не выглядят одинаково.

## Проверено

```
vis OK: zones=4 active=3 problems=0
hud_test 0 · pause OK · controls OK · ui OK · perk_effects 100/100
hazard OK: maps=13 solid=495 destructible=555 decor=268 events=39 kinds=24 problems=0
```

Новый тест `SURW_VIS_TEST=1` создаёт по зоне каждого типа и проверяет: визуал привязан, узор соответствует типу, радиус передан, переход из предупреждения в активную фазу состоялся, перерисовка без ошибок. Импорт Godot 4.7.2 — exit 0. Скриншоты не сохраняются — по вашему указанию.

## Не проверено

- Живой вид: видеодрайвера в среде сборки нет, проверены структура, цвета и состояние фаз.
- Насколько яркой покажется кайма на вашем мониторе: если зоны будут слишком кричащими, ослаблю прозрачность каймы одним параметром.
