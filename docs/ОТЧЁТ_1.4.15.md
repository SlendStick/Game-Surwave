# Surwave 1.4.15 — чит-консоль

Клавиша **`~`** (она же «ё» на русской раскладке) в забеге открывает строку ввода внизу по центру. Команда **`wuss menu`** (можно `wuss` или `wussmenu`) открывает чит-меню. Повторное `~` или **Esc** закрывает, забег при этом продолжается с той же секунды.

## Что в меню

Панель в готическом камне, прокручивается колесом, всё по-русски:

| Раздел | Что делает |
| --- | --- |
| **ИГРОК** | бессмертие (вкл/выкл), лечить, +1 к максимальному HP, бесконечные патроны, опыт (+1000 / +10000 / +1 уровень), множитель урона игрока (÷2 / ×2 / ×1), скорость игрока (÷1.5 / ×1.5 / ×1) |
| **КОНФИГУРАЦИЯ ПЕРСОНАЖА** | урон оружия ±20 %, темп стрельбы ±20 %, размер магазина (−1 / +1 / ×2), +1 снаряд в залпе, кнопка «сброс» к базовым значениям |
| **ВРАГИ** | здоровье врагов ×N, урон врагов ×N, скорость врагов ×N — **сразу для живых и для всех следующих спавнов**, заморозка врагов, «убить всех», «очистить зону» вокруг игрока, счётчик живых |
| **ВРЕМЯ** | множитель времени 0.25 / 0.5 / 1 / 2 / 4, «пауза мира» (0.02) и возврат к 1 |
| **СПАВН ВРАГОВ** | кнопка на каждого обычного врага из базы (мини-боссы вынесены отдельно) |
| **БОССЫ И МИНИ-БОССЫ** | все 14 боссов карт + САТАНАИЛ отдельной кнопкой + мини-босс текущей карты |

Опыт выдаётся честно через `add_xp` — открываются карточки выбора уровня, поэтому меню перед выдачей само закрывается. «Убить всех» обходит броню, щиты и добивание QTE, иначе боссы оставались бы живы.

## Как устроено

- `scripts/ui/cheat_console.gd` — сама консоль: `CanvasLayer` со слоем 50, всегда активна (`PROCESS_MODE_ALWAYS`), поэтому работает во время паузы. Рисуется кодом, внешних ассетов нет.
- Меню открывается только в забеге; при открытом меню Esc принадлежит консоли, пауза игры не срабатывает.
- Все читы — отдельные поля `GameManager` (`cheat_dmg`, `cheat_speed`, `cheat_enemy_hp`, `cheat_enemy_dmg`, `cheat_enemy_speed`, `cheat_frozen`), они **сбрасываются в начале каждого нового забега**, вместе с `Engine.time_scale = 1.0`. Обычный забег без читов не меняется.
- Урон игрока: множитель в `current_damage()`; скорость: множитель в расчёте движения; бесконечные патроны: расход магазина не уменьшается; заморозка врагов: их `tick` пропускается.

Тест `SURW_CHEAT_TEST=1` (44 строки, 67 кнопок) проверяет по шагам: `~` открывает строку и ставит паузу → Esc закрывает и снимает паузу → неизвестная команда даёт подсказку → `wuss menu` открывает меню → бессмертие держит удар 99 (и без него урон снова проходит) → +опыт даёт уровень → бесконечные патроны не тратят магазин → спавн врага и босса → множители HP и урона действуют на **живых** врагах → заморозка держит врагов на месте → скорость врагов ×0 останавливает уже заспавненного → время переключается и возвращается → урон игрока ×3 растёт → «убить всех» не оставляет живых → закрытие меню снимает паузу. Плюс проверки раскладки: ширина строк ≤ панели, элементы в пределах экрана, разделы на месте. Импорт Godot 4.7.2 — exit 0, `--headless` прогон 60 с на `abyss` без ошибок.

## Не проверено

- **Живой вид и печать в строке**: в среде сборки нет видеодрайвера, клавиатуры и мыши — проверены структура, геометрия и вся логика, но не то, как вы наберёте `wuss menu` руками. Если строка окажется мелкой на 1440×900 — увеличу шрифт.
- Работа с реальной русской раскладкой: покрытие сделано через `physical_keycode = KEY_QUOTELEFT`, то есть по физической клавише «ё», независимо от языка.
- Насколько удобно, что при открытой консоли Esc не открывает меню паузы — если хотите наоборот, скажите.
