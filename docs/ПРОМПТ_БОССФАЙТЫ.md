# 📋 РАЗДЕЛ 1. КОНЦЕПЦИЯ И ФИЛОСОФИЯ

## 1.1 ЧТО ТАКОЕ БОСС-ФАЙТ?

**Босс-файт** — это кульминационное сражение с уникальным противником, которое проверяет ВСЕ навыки игрока:
- Понимание механик персонажа
- Знание паттернов атак босса
- Управление ресурсами (HP, патроны, перки)
- Реакцию и тайминг

**Философия Surwave:**
- **Читаемость** — каждая атака должна быть предсказуемой по визуальным подсказкам
- **Справедливость** — игрок ВСЕГДА может избежать урона при правильном тайминге
- **Награда** — победа над боссом должна давать чувство достижения
- **Повторяемость** — боссы должны быть интересны при многократных сражениях

## 1.2 СТРУКТУРА БОСС-ФАЙТА

**Типичная структура (30-минутный забег):**
```
0:00-15:00 — Обычная фаза (накопление сил)
├── Игрок собирает перки, оружие
├── Враги становятся сильнее
└── Подготавливается к боссу

15:00 — Появление первого босса
├── Кинематографический вход
├── 3-5 фаз сражения
├── Награда: 500 XP + реликвия
└── Длительность: 3-5 минут

15:00-30:00 — Продолжение забега
├── Больше элитных врагов
├── Подготовка к финальному боссу
└── Накопление ресурсов

30:00 — Финальный босс (Сатана/Секретный босс)
├── Самая сложная битва
├── 5-7 фаз сражения
├── Мега-фазы (трансформации)
├── Награда: 2000 XP + 5 реликвий
└── Длительность: 8-15 минут
```

```gdscript
func check_phase_transition() -> void:
    var hp_ratio = current_hp / max_hp
    
    if hp_ratio <= 0.70 and phase == 1:
        start_phase_transition(2)
    elif hp_ratio <= 0.40 and phase == 2:
        start_phase_transition(3)
    elif hp_ratio <= 0.15 and phase == 3:
        start_phase_transition(4)  # "Ярость"

func start_phase_transition(new_phase: int) -> void:
    # 1. Остановить босса
    is_attacking = false
    is_moving = false
    
    # 2. Кинематографический переход
    camera.dramatic_zoom(1.5, duration=2.0)
    screen_shake(12, duration=0.5)
    slow_motion(0.3, duration=1.5)
    
    # 3. Визуальные эффекты
    spawn_phase_transition_vfx()
    play_phase_sound()
    
    # 4. Показать текст
    show_phase_text("Фаза " + str(new_phase))
    
    # 5. Переход (2.5 сек)
    yield(get_tree().create_timer(2.5), "timeout")
    
    # 6. Активировать новую фазу
    phase = new_phase
    enable_phase_attacks()
    
    # 7. Возврат к бою
    camera.zoom_to(1.0, duration=1.0)
    resume_combat()
```

### AI поведение
```gdscript
class InfernalLord extends Boss:
    var phase: int = 1
    var attack_cooldowns = {
        "fireball": 0.0,
        "fire_pillar": 0.0,
        "summon": 0.0,
        "hellfire": 0.0
    }
    
    func _process(delta: float) -> void:
        # Обновить кулдауны
        for attack in attack_cooldowns:
            attack_cooldowns[attack] -= delta
        
        # Выбрать атаку
        if can_attack("hellfire") and hp_ratio <= 0.15:
            perform_attack("hellfire")
        elif can_attack("summon") and hp_ratio <= 0.40:
            perform_attack("summon")
        elif can_attack("fire_pillar") and hp_ratio <= 0.70:
            perform_attack("fire_pillar")
        elif can_attack("fireball"):
            perform_attack("fireball")
        
        # Движение к игроку
        move_towards_player(delta)
    
    func can_attack(attack_name: String) -> bool:
        return attack_cooldowns[attack_name] <= 0.0
    
    func perform_attack(attack_name: String) -> void:
        match attack_name:
            "fireball":
                cast_fireball()
                attack_cooldowns["fireball"] = 3.0 / phase
            "fire_pillar":
                cast_fire_pillar()
                attack_cooldowns["fire_pillar"] = 5.0 / phase
            "summon":
                cast_summon_demons()
                attack_cooldowns["summon"] = 8.0
            "hellfire":
                cast_hellfire()
                attack_cooldowns["hellfire"] = 10.0
```

## 6.1 СИСТЕМА ПРИНЯТИЯ РЕШЕНИЙ

**Дерево решений:**
```gdscript
class BossAI:
    func decide_action() -> String:
        # Приоритет 1: Ультимативные атаки (если доступны)
        if can_use_ultimate() and hp_ratio <= 0.15:
            return "ultimate_attack"
        
        # Приоритет 2: Призывы (если мало миньонов)
        if active_minions < 3 and can_summon():
            return "summon"
        
        # Приоритет 3: AoE атаки (если игрок рядом)
        if distance_to_player < 128 and can_aoe():
            return "aoe_attack"
        
        # Приоритет 4: Дальнобойные атаки
        if can_ranged_attack():
            return "ranged_attack"
        
        # Приоритет 5: Движение к игроку
        return "move_to_player"
    
    func can_use_ultimate() -> bool:
        return ultimate_cooldown <= 0.0 and hp_ratio <= 0.15
    
    func can_summon() -> bool:
        return summon_cooldown <= 0.0 and active_minions < 5
```

1. **14 обычных боссов** + **2 секретных** с уникальными механиками
2. **3-7 фаз** у каждого босса с переходами
3. **4-12 уникальных атак** у каждого босса
4. **Визуальные подсказки** для каждой атаки (читаемость)
5. **Динамическая камера** (тряска, зум, slow-mo)
6. **Эпические катсцены** (появление, смерть, трансформации)
7. **Мега-фазы** для секретных боссов
8. **Масштабирование** по игрокам и уровню тьмы
9. **Система наград** (XP, реликвии, души)
10. **Звук и музыка** для атмосферы

## 10.2 ФИЛОСОФИЯ ДИЗАЙНА

**Босс-файты должны:**
- Быть **справедливыми** (игрок всегда может избежать урона)
- Быть **эпичными** (визуально и звуково)
- Быть **запоминающимися** (уникальные механики)
- Быть **вознаграждающими** (чувство достижения)
- Быть **повторяемыми** (интересны при многократных сражениях)
