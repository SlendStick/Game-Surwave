# Сетевой кооп (LAN и интернет)

Сетевая игра — это полноценный кооп по ENet: до 4 игроков в одном забеге, у каждого
свой герой, оружие и прокачка; враги, боссы, волны и лут считаются один раз на хосте.

## Как играть в локальной сети

1. Запустить игру на обоих компьютерах (версия игры должна совпадать — протокол 2).
2. Хост: главное меню → **СЕТЕВАЯ ИГРА** → ввести имя → **СОЗДАТЬ СЕРВЕР**.
3. Клиент: **ОБНОВИТЬ СПИСОК ЛОКАЛЬНОЙ СЕТИ** → нажать на найденный хост.
4. В лобби каждый выбирает героя и оружие; карту выбирает хост.
5. Хост нажимает **НАЧАТЬ ЗАБЕГ** — забег стартует у всех одновременно.

Если автоматический поиск не сработал (например, сеть режет широковещательные UDP-пакеты),
клиент вводит IPv4-адрес хоста в поле «IP ХОСТА» и нажимает **ПОДКЛЮЧИТЬСЯ**.
Свой адрес хост видит в строке статуса лобби.

## Как играть через интернет

Вариант А — проброс портов (самый простой):

- на роутере хоста пробросить **UDP 7777** на его локальный IP;
- клиенты вводят внешний IP хоста (или его домен) и нажимают **ПОДКЛЮЧИТЬСЯ**;
- порт меняется в настройках («СЕТЬ» → «Порт») и должен совпадать у всех участников.

Вариант Б — виртуальная локальная сеть (Radmin VPN, ZeroTier, Hamachi, Tailscale):

- все игроки ставят одно приложение и попадают в одну виртуальную сеть;
- хост создаёт сервер, клиенты находят его кнопкой обновления LAN-списка
  либо вводят выданный виртуальный IP.

Порт обнаружения — **UDP 7778** (только для автопоиска в LAN, для интернета не нужен).

## Что синхронизируется

- **20 Гц** — состояния игроков: позиция, направление прицела, HP, экипировка, движение.
- **10 Гц** — снапшот мира хоста: враги (id, тип, позиция, HP, элитность), вражеские
  снаряды, подборы, опыт/золото/души/уровень/убийства/время.
- Урон по врагам засчитывает только хост; клиент шлёт `request_damage`, хост отвечает
  уроном по игроку и событиями (подбор, взрыв, босс-фаза).
- Клиент рисует «призраков» врагов и подборов по снапшотам, поэтому картинка совпадает
  у всех, но истина по HP и смерти всегда на хосте.

## Если соединение не устанавливается

| Симптом | Что проверить |
|---|---|
| «Не удалось подключиться» | IP/порт, файрвол Windows (разрешить игру в частных сетях), версия игры |
| Хост не виден в LAN-списке | широковещательные пакеты блокируются — введите IP вручную |
| Через интернет не подключается | проброс UDP 7777 на роутере, внешний IP (а не 192.168.x.x) |
| Игра «дёргается» у клиента | интернет-канал: снапшоты идут 10 раз в секунду, при плохом канале помогают настройки графики |

## Ограничения текущего прототипа

- Хост — авторитет по миру; при выходе хоста сессия завершается у всех.
- Сохранение прогресса (золото, души, осколки) пишется каждым игроком локально по итогам забега.
- Голосового чата нет: общение — вне игры.
